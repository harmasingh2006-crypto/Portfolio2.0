## 🚀 How to Deploy FREE on GitHub Pages (Step-by-Step)

### Step 1 — Create a GitHub Account (if you don't have one)
1. Go to **https://github.com**
2. Click **Sign up**
3. Enter your email, create a password, and choose a username (e.g., `harmasingh2006`)
4. Verify your email

---

### Step 2 — Create a New Repository
1. On GitHub, click the **"+"** button (top right) → **New repository**
2. Name it exactly: `harmasingh2006.github.io`
   - ⚠️ **Replace `harmasingh2006` with YOUR actual GitHub username**
3. Set visibility to **Public**
4. Click **Create repository**

---

### Step 3 — Upload Your Portfolio Files
**Option A — Using GitHub Website (Easiest, No coding needed):**
1. Open your new repository
2. Click **"uploading an existing file"** link
3. Drag and drop ALL files from this folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `avatar.png`
4. Click **Commit changes**

**Option B — Using Git (If you have Git installed):**
```bash
cd harman-portfolio
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/harmasingh2006/harmasingh2006.github.io.git
git push -u origin main
```

---

### Step 4 — Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** tab
3. Click **Pages** in the left sidebar
4. Under **Source**, select **Deploy from a branch**
5. Choose branch: **main** | folder: **/ (root)**
6. Click **Save**

---

### Step 5 — Visit Your Live Website! 🎉
After 1-3 minutes, your portfolio will be live at:

```
https://harmasingh2006.github.io
```

*(Replace `harmasingh2006` with your actual GitHub username)*

| Your name, contact details | `index.html` – Hero & Contact sections |

| Change colors | `style.css` – `:root` CSS variables at top |
| Add your real photo | Replace `avatar.png` with your photo |
